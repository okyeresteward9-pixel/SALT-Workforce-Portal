SALT UI Step 2 - Dashboard migration

1. Back up your current templates/dashboard.html.
2. Copy templates/base.html and templates/dashboard.html into your project.
3. Copy static/css/salt-core.css into static/css/.
4. Keep your existing static/style.css, salt-design-system.css, and salt-mobile-pwa.css.
5. Test /dashboard before migrating the next page.

This step moves the shared shell to base.html while preserving the existing dashboard content and page scripts.
